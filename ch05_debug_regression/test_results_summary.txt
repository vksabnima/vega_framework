RTL BUGS FIXED (ahb2apb_bridge.sv rewritten to match ahb2apb_spec.pdf):
  1. CTRL register layout: Implemented per Table 6 — bit[0]=ENABLE(reset=1),
     bit[1]=SOFT_RST(self-clearing), bit[3]=ERR_INT_EN, bits[6:4]=TIMEOUT_VAL(reset=111),
     bit[7]=TIMEOUT_EN. Reset value = 0x0000_0071. (Was 0x0000_0100, wrong bit mapping.)
  2. SOFT_RST mechanism: Added self-clearing soft reset — clears STATUS error bits,
     ERROR_ADDR, ERROR_INFO, resets FSM, clears APB outputs. (Was missing entirely.)
  3. ENABLE bit: Added proper ENABLE gate — FSM only initiates APB transfers when
     ENABLE=1, but register accesses always work regardless of ENABLE. (Was missing.)
  4. STATUS register: Implemented per Table 7 — bit[0]=READY(RO), bit[1]=BUSY(RO),
     bit[4]=ADDR_ERR(W1C), bit[5]=PSLVERR(W1C), bit[6]=TIMEOUT_ERR(W1C),
     bit[7]=ERR_INT(W1C). Reset value = 0x0000_0001. (Was read-only, no W1C, inverted
     READY/BUSY semantics.)
  5. Timeout formula: Implemented 2^(TIMEOUT_VAL+4) via case-statement lookup table
     (VAL=0 -> 16 cycles, VAL=7 -> 2048 cycles). 12-bit counter. (Was direct comparison.)
  6. ERROR_INFO encoding: Implemented per Table 9/10 — [15:8]=ERR_BEAT,
     [7:4]=ERR_TYPE(0=none,1=addr,2=timeout,3=PSLVERR), [3]=ERR_WRITE, [2:0]=ERR_SIZE.
     (Was different bitmask layout.)
  7. READY/BUSY during register reads: ST_REG_READ treated as idle state so reading
     STATUS doesn't show BUSY=1. (Was treating all non-IDLE as BUSY.)
  8. Register access when ENABLE=0: Register range (0xF00-0xFFF) bypasses ENABLE check
     so configuration works even when bridge is disabled. (Was blocked by ENABLE.)
  9. ERPT-6 error_captured: Added error_captured flag so only the first error is recorded
     in ERROR_ADDR/ERROR_INFO until error bits are cleared via W1C. (Was missing.)

TB BUGS FIXED:
  1. Invalid hex literals: 32'hBAD0_ADDR, 32'hBAD0_DATA, 32'hBAD_ADDR0 — replaced
     with valid hex values.
  2. Class name mismatches in reset_003/004 tests: ahb_mst_reset_00X_pre_seq ->
     ahb_mst_reset_00X_seq.
  3. APB slave driver PSLVERR timing: Pre-drive during SETUP phase due to clocking
     block output #1 skew.
  4. AHB master driver two-clock wait: Extra @(vif.drv_cb) for input sampling timing.
  5. APB slave monitor post_randomize() overwriting PSLVERR.
  6. AHB master monitor post_randomize() overwriting HTRANS/HBURST.
  7. Updated 14 sequence files + 1 test file to match new RTL register layout/behavior.
  8. reg_access_005/006 sequences: Added W1C clear between consecutive errors for
     ERPT-6 error_captured compatibility.
  9. protocol_003 sequence: Removed PSLVERR step (test doesn't set pslverr_inject).
