[VERIFIED - high-level functional description] The RTL implements a
single-clock-domain bridge between an AHB-like source-side bus and an
APB-like peripheral-side bus, including:

  - 21 ports total across the two interfaces (32-bit address, 32-bit
    data, transfer-control, ready/response, and error signaling).
  - A finite state machine for protocol conversion (IDLE -> SETUP -> ACCESS).
  - A 4-register configuration block (CTRL, STATUS, ERROR_ADDR,
    ERROR_INFO) accessible via the source-side bus at a configurable
    base address.
  - Error detection: address-range decode, peripheral-side timeout,
    and peripheral-side error-response propagation.
  - A self-clearing soft reset (CTRL.SOFT_RST) and an asynchronous
    hard reset (HRESETn).
  - Configurable timeout via CTRL.TIMEOUT_EN / CTRL.TIMEOUT_VAL.
